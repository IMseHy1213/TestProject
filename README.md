# Real Estate Recommendation Agent (토지)

부모님이 운영하시는 부동산의 **토지 매물**을 자동으로 수집하고, 중복·오류 매물을 걸러낸 뒤,
손님의 문의를 이해해서 **가장 알맞은 매물을 순위대로 추천**하는 AI Agentic System 입니다.
추천한 매물이 마음에 들지 않으면 **다음 순위 매물**을 보여주고, 새 매물이 들어오면 저장된 손님에게 **먼저 제안**합니다.
**브라우저로 쓰는 웹 서비스**로 동작합니다 (휴대폰 화면 지원).

- 언어: Python 3.10+
- LLM: Claude Sonnet 5 (또는 Sonnet 4.6), GPT-5.6 Luna 등. **LLM 이 없어도 규칙 기반으로 동작합니다.**
- 매물 데이터: 프로젝트 폴더 안의 **`매물`** 폴더에 넣은 엑셀(.xlsx) 파일 (처음 실행하면 자동으로 만들어짐)

## 1. 무엇을 하나요?

| 기능 | 설명 |
|---|---|
| 매물 수집 | 매물 폴더의 엑셀(.xlsx/.xls)·CSV·JSON·텍스트 메모를 하위 폴더까지 모두 읽습니다. 하위 폴더 이름에 `네이버`, `써브` 가 있으면 출처를 자동 표시합니다. |
| 오류 필터링 | 주소·면적·가격 누락, 비현실적인 평당가(단위 입력 실수), 범위를 벗어난 좌표 등을 찾아 추천에서 제외하고 보고서로 남깁니다. |
| 중복 제거 | 같은 땅이 장부·네이버·써브에 각각 올라가 있어도 (주소 표기가 조금 달라도) 하나로 합칩니다. 최신 등록 정보를 대표로 쓰고, 가격이 달랐던 기록도 보관합니다. |
| 문의 이해 | "양평 쪽 전원주택 지을 땅 200평 정도, 3억 이하, 맹지 제외" 같은 문장을 지역/예산/면적/지목/용도지역/목적/도로 조건으로 바꿉니다. |
| 맞춤 추천 | 100점 만점으로 점수를 매겨 1순위부터 보여주고, 왜 추천했는지(장점)와 확인할 점(전용허가, 예산 초과 등)을 함께 설명합니다. |
| 다음 순위 | 손님이 "마음에 안 들어요"라고 하면 바로 2순위, 3순위 매물을 보여줍니다. "좀 더 싼 걸로" 같은 피드백을 주면 조건을 고쳐서 다시 순위를 매깁니다. 거절한 매물은 기억해서 다시 추천하지 않습니다. |
| 피드백 학습 | 거절·관심 표시에서 손님 취향을 배웁니다. 예) "너무 좁아요"로 거절 → 면적 중요도 ↑ → 다음 순위에 넓은 땅이 먼저 나옴. 손님별로 저장되어 다음 상담에도 이어지고, 사무실 전체 피드백은 공통 모델로 쌓여 처음 오는 손님에게도 반영됩니다. |
| 선제 제안 | 손님 조건을 저장해 두면, 매물 폴더에 새 매물이 들어올 때 조건에 맞는 손님에게 먼저 알려줍니다. |
| 공공데이터/GIS (선택) | 국토부 토지 실거래가로 지역 시세를 구해 "시세 대비 저렴" 가점, 브이월드로 주소→좌표 변환. |

## 2. 에이전트 구조

```
            ┌────────────────────────── 선제 제안 (watch) ──────────────────────────┐
            ▼                                                                       │
 [1 관찰] 수집 ──► [2 정제] 오류·중복 필터 ──► SQLite 저장 (신규/변경 감지) ───────────┘
 매물폴더 / 네이버·써브 내보내기 / 공공데이터·GIS
                                             │
 손님 문의 ──► [3 이해] LLM 구조화 ─(실패시)─► 규칙 기반
                                             ▼
                          [4 계획·실행] 필수조건 필터 → 점수화 → 순위
                                 맞는 매물이 없으면 "해당 조건에 맞는 매물이 없습니다." (다른 지역·조건 매물로 대체하지 않음)
                                             ▼
```

### 점수 기준 (100점)

지역 15 · 가격 25 · 면적 20 · 지목 15 · 용도지역 10 · 도로 5 · 특징 키워드 5 · 최신 등록 5
(+ 실거래 시세보다 15% 이상 저렴하면 가점 5)

- 손님이 말하지 않은 항목은 중립 점수(70%)를 줍니다.
- 목적(전원주택/창고/공장/농사/근린생활/캠핑장/태양광/투자)별로 잘 맞는 지목·용도지역 표가 있습니다
  (`recommender.py` 의 `PURPOSE_PROFILE`). 부모님의 실무 경험에 맞게 숫자를 고치면 됩니다.
- 예산 10% 넘게 초과, 맹지(도로 필요 시), 제외 조건, 지역 불일치, 계약완료·보류 매물은 후보에서 뺍니다.

### 목적 조건: "창고를 지을 수 있는 토지" (`land_use.py`)

손님이 창고·공장·전원주택·근린생활(카페/상가) 같은 **용도**를 말하면, 그 용도로 지을 수 없는 땅은 추천하지 않습니다.
지역·가격은 손님이 말했을 때만 적용합니다.

| 검색 | 결과 |
|---|---|
| 음성군에 위치한 창고를 지을 수 있는 토지 | **가격 상관없이** 음성군의 창고 가능 토지 |
| 창고를 지을 수 있는 토지 | **지역 상관없이** 창고 가능 토지 |

판단 근거 (화면에 "창고 가능: …"으로 표시):
1. 매물 정보·폴더 이름에 용도가 적혀 있음 (예: `창고 건축허가 득`, `(물류부지)`)
2. 지목이 이미 그 용도 (창고용지·공장용지)
3. 용도지역이 허용 (창고: 계획관리·자연녹지·공업·상업지역 등 / 농림·보전관리·생산녹지는 불가) - 지목이 전·답·임야면 "전용허가 필요" 안내
4. 용도지역이 비어 있으면 지목이 대·잡종지일 때만 "용도지역 확인 필요"와 함께 추천

> 실제 건축 가능 여부는 토지이용계획확인원·지자체 조례로 최종 확인해야 합니다.

### 생성형 AI 취향 학습 (`ai_learning.py`)

GPT/Claude 가 연결되어 있으면, 손님이 매물을 거절하거나 관심을 보일 때마다 **지금까지의 반응 기록 전체**를 AI 에게 보내
"이 손님이 실제로 중요하게 여기는 것"을 추론하게 합니다. (지번·연락처는 보내지 않습니다)
- AI 가 정리한 취향은 화면에 **🤖 AI가 파악한 취향** 으로 표시됩니다. 예) "가격보다 넓은 면적과 계곡 인접 땅을 중시하십니다."
- AI 의 판단은 검증 후 반영됩니다: 항목 중요도(↑↓), 선호/비선호 특징·지목, 찾는 특징 추가.
  **매물을 빼는 조건(제외)은 손님이 직접 말한 단어일 때만** 반영해서, AI 의 추측만으로 매물이 사라지지 않게 했습니다.
- 손님이 직접 요구한 조건은 AI 가 '비선호'로 바꾸지 못합니다.
- AI 를 쓸 수 없으면(키 없음·연결 실패) 아래 규칙 기반 학습만으로 계속 동작합니다.

### 피드백 학습 방식 (`preference.py`)

| 손님 반응 | 배우는 것 |
|---|---|
| 거절 (이유 없음) | 거절한 매물이 다른 후보보다 **잘했던 항목은 중요도 ↓, 못했던 항목은 중요도 ↑** (온라인 학습) |
| 거절 + 이유 ("너무 비싸요", "채광이 별로") | 이유에 해당하는 항목(가격, 특징 …)의 중요도를 크게 ↑ |
| 관심 표시 (`l`) | 그 매물의 강점 항목 중요도 ↑, 지목·용도지역·특징(남향, 계곡 …)을 '선호'로 기록 |

- **"너무 비싸요"로 넘기면 다음 매물은 반드시 방금 매물보다 저렴하고, "너무 좁아요"면 반드시 더 넓습니다.**
  (너무 넓어요 → 더 좁게, 너무 싸요 → 더 비싸게도 같은 방식) 조건이 쌓이므로 "비싸요" 후 "좁아요"면 둘 다 만족하는 매물만 나오고,
  그런 매물이 없으면 엉뚱한 매물 대신 "더 없습니다"라고 안내합니다. `← 이전 매물`을 누르면 그 조건도 함께 되돌아갑니다.
- 손님이 직접 요구한 조건(예: 채광)은 거절 한 번으로 '비선호'가 되지 않도록 보호합니다.
- 데이터가 적을 때 과하게 반응하지 않도록 중요도 변화 폭과 선호 가점(최대 ±6점)에 상한을 두었습니다.
- 학습 결과는 상담 중 `w` 로 볼 수 있습니다. (예: `중요도: 가격 24%, 면적 21% … / 선호: 남향`)

## 3. VS Code 에서 설치·실행하기

### 처음 한 번만 하는 준비

1. **파이썬 설치**: https://www.python.org 에서 Python 3.10 이상 설치
   (설치 첫 화면에서 **"Add python.exe to PATH" 체크**)
2. **VS Code 확장 설치**: VS Code 왼쪽 확장(Ctrl+Shift+X)에서 **Python** (Microsoft) 설치
3. **프로젝트 폴더 열기**: VS Code 메뉴 **파일 → 폴더 열기** → `C:\Users\user\projectISH\Project` 선택
   (⚠ `main.py` 파일 하나만 열면 안 되고, **폴더 전체**를 열어야 합니다)
4. **터미널 열기**: 메뉴 **터미널 → 새 터미널** (Ctrl+`)
   터미널 앞부분이 `PS C:\Users\user\projectISH\Project>` 인지 확인하세요.
5. **가상환경 만들고 패키지 설치** (터미널에 한 줄씩 입력):
   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
   > "스크립트를 실행할 수 없습니다" 오류가 나면 먼저
   > `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 를 실행하고 `Y` 를 입력한 뒤 다시 하세요.
6. **인터프리터 선택**: Ctrl+Shift+P → `Python: Select Interpreter` → `.venv` 가 들어간 항목 선택
7. **API 키**: 아래 **GPT 연동** 순서대로 `setup-key` 를 실행하면 `.env` 가 자동으로 만들어집니다. (키가 없어도 규칙 기반으로 동작)

### GPT 연동 (API 키 넣기)

**방법 1 - 코드 파일에 직접 넣기 (가장 간단)**
1. 웹 서비스를 한 번 실행하면 프로젝트 폴더에 **`my_api_key.py`** 파일이 생깁니다. (VS Code 왼쪽 탐색기에서 보임)
2. 파일을 열어 `OPENAI_API_KEY = ""` 의 따옴표 안에 키를 붙여넣고 **저장(Ctrl+S)**
   ```python
   OPENAI_API_KEY = "sk-proj-여기에_키"
   ```
3. 웹 서비스를 다시 켭니다. (켜 둔 상태라면 3분 안에 자동으로 연결됩니다)
   → 첫 화면에 **"AI(GPT/Claude)가 문장을 이해합니다"** 가 나오면 완료

**방법 2 - 웹 관리자 화면에서 넣기**: 관리자 → "AI 연결" 칸에 키 붙여넣기 → **저장하고 연결 확인**
→ 서버를 다시 켜지 않아도 바로 연결되고, 실제로 GPT 에 한 번 물어봐서 "✅ GPT 연결 성공" 을 보여줍니다.

> `my_api_key.py` 는 `.gitignore` 에 들어 있어 **GitHub 에 올라가지 않고**, `git pull` 해도 지워지지 않습니다.
> 키는 비밀번호와 같으니 카톡·메일로 보내거나 다른 파일에 복사하지 마세요.
> 키를 찾는 순서: `my_api_key.py` → `.env` → 시스템 환경변수

### GPT 와 Claude 를 골고루 쓰기

GPT 키와 Claude(Anthropic) 키를 **둘 다** 넣으면 자동으로 두 AI 를 번갈아 씁니다.
- 요청마다 **최근 1분 동안 덜 쓴 쪽**에 먼저 보냅니다 → 한쪽에 몰리지 않아 분당 한도(429)에 훨씬 덜 걸립니다.
- 한쪽이 한도에 걸리거나 응답이 늦으면 **다른 쪽이 바로** 받습니다. 둘 다 안 될 때만 규칙 기반.
- 첫 화면에 **"AI(GPT + Claude)가 문장을 이해합니다"** 가 나오면 둘 다 연결된 것입니다. 관리자 화면 "AI 연결" 칸에 AI 별 사용 횟수가 나옵니다.

Claude 키 넣는 방법 (둘 중 하나)
1. `my_api_key.py` 의 `ANTHROPIC_API_KEY = ""` 따옴표 안에 `sk-ant-...` 키를 붙여넣고 저장
2. 관리자 화면 → "AI 연결" → **Claude(Anthropic) API 키** 칸에 붙여넣기 → 저장하고 연결 확인

### 웹 화면 구성

**손님 화면** (`/`) - 이름 입력 없이 검색창 하나로 사용합니다.
1. 검색창에 "음성군 채광이 좋은 2억원대 땅" 처럼 입력 → **찾아보기**
2. **1순위** 매물 카드 (가격·면적·지목·용도지역·도로·장점·확인할 점·AI 설명)
3. **[마음에 안 들어요 → 다음 순위 보기]** 를 누르면 2순위, 3순위 … 로 넘어갑니다.
   - 빠른 이유 버튼(너무 비싸요 / 너무 좁아요 / 위치·도로·채광이 별로예요)을 누르면 이유를 학습해 다음 순위를 다시 고릅니다.
   - "다른 요청" 칸에 "좀 더 싼 걸로", "여주 쪽도" 를 쓰면 조건을 바꿔 다시 찾습니다.
   - ♥ 관심 있어요 / ← 이전 매물 / 다음 후보 미리보기
4. 손님 화면에는 **소유자 연락처·정확한 지번이 보이지 않습니다** (예: `음성군 금왕읍 무극리 ***`).
5. 매물 카드에는 엑셀에 적힌 **매물번호**가 함께 나옵니다 (장부의 '매물번호/관리번호' 열, 매물 폴더 엑셀의 '매물번호' 칸).
   엑셀에 매물번호가 없으면 표시하지 않습니다. 매물 정보 칸은 가격·면적·지목·용도지역이고, 도로 조건은 관리자 정보 칸에 나옵니다.

**관리자 화면** (`/admin`, 화면 오른쪽 위 **관리자**)

처음 로그인하기
1. 웹 서비스를 켠 PC 의 브라우저에서 오른쪽 위 **관리자** 를 누릅니다. (주소: http://127.0.0.1:8000/admin)
2. 처음에는 **"관리자 비밀번호 정하기"** 화면이 나옵니다. 8자 이상 비밀번호를 두 번 입력 → **비밀번호 정하고 로그인**
3. 다음부터는 같은 곳에서 그 비밀번호로 로그인합니다. 다 쓰면 오른쪽 위 **로그아웃**.

- 터미널로 정하려면 VS Code 실행 목록의 **⓪ 관리자 비밀번호 정하기 / 바꾸기** (또는 `python main.py set-admin-password`)
- 비밀번호 바꾸기: 관리자 화면의 **관리자 비밀번호 바꾸기** 칸
- 비밀번호를 잊었다면: 서버 PC 에서 `data/admin_password.json` 을 지운 뒤 다시 정하기
- 비밀번호는 복원할 수 없는 해시로만 `data/admin_password.json` 에 저장되고 GitHub 에 올라가지 않습니다.
- 보안: 처음 비밀번호 정하기는 **서버를 켠 PC 에서 접속했을 때만** 됩니다 (휴대폰·다른 PC 에서는 불가).
  비밀번호를 5번 틀리면 5분 동안 로그인이 잠깁니다.
- `.env` 에 `REA_ADMIN_PASSWORD=...` 를 적어 두면 그 값이 우선합니다.

- 매물 폴더 다시 읽기, 매물 파일(엑셀/CSV) 올리기, 오류·중복 보고서, AI 연결 상태, 사무실 전체 학습 현황

**매물 추가·수정** (관리자 로그인 후 관리자 화면 → **매물 추가·수정**)
- **＋ 새 매물 추가**: 소재지·면적·매매가(필수)와 지목·용도지역·도로·상태·특이사항·연락처를 입력 → **매물 추가**
  - 매물 폴더의 `웹입력/웹입력매물.xlsx` 에 한 줄로 저장되고 손님 검색에 바로 나옵니다. (엑셀로 열어 볼 수 있고, 백업은 매물 폴더만 복사하면 됨)
  - 저장 전에 검사합니다: 빈 칸, 숫자가 아닌 면적, 말이 안 되는 평당가(단위 실수), **이미 있는 같은 땅**(중복)
  - 엑셀에서 `웹입력매물.xlsx` 를 열어 둔 채로 저장하면 실패하니 엑셀을 닫고 저장하세요.
- **매물 목록 / 수정**: 주소·매물번호·지목으로 찾아 **수정** → 가격·상태(거래가능/보류/계약완료)·특이사항 등 고치고 **수정 저장**
  - 원본 엑셀 파일은 건드리지 않고 고친 항목만 프로그램에 저장해 덮어씁니다. 매물 폴더를 다시 읽어도 유지됩니다.
  - **원래 엑셀 내용으로 되돌리기**: 고친 내용을 모두 취소
  - **목록에서 숨기기(삭제)**: 손님 검색에서 빠집니다. 파일은 지워지지 않고 '숨긴 매물' 에서 다시 보이게 할 수 있습니다.
  - 보류·계약완료로 바꾼 매물은 손님 검색에 나오지 않습니다.
- 관리자로 로그인한 상태의 검색 결과 카드에도 **이 매물 수정** 링크가 있습니다.

**엑셀 파일·폴더 올리기** (관리자 화면 "매물 파일·폴더 올리기", 매물 관리 "📁 엑셀 파일·폴더로 매물 추가", 매물 수정 화면 "이 매물의 파일")
- **📄 엑셀 파일 고르기**: 여러 파일을 한 번에 고를 수 있습니다.
- **📁 폴더째 고르기**: 폴더 안의 하위 폴더 구조를 그대로 매물 폴더에 저장합니다.
  - 예) 저장할 폴더 **음성군** 을 고르고 `음성군 감곡면 문촌리 417-2 외 36필지(물류부지)` 폴더를 올리면
    `매물\음성군\음성군 감곡면 문촌리 417-2 외 36필지(물류부지)\...xlsx` 로 저장되어 **매물 1건**으로 읽힙니다.
  - `음성군` 폴더 자체를 "매물 폴더 바로 아래" 로 올려도 됩니다.
- **저장할 폴더**: 매물 폴더 안의 기존 폴더(음성군, 기타지역 …) 중 고르거나 **＋ 새 폴더 만들기**(예: 진천군)
- **매물 수정 화면에서 올리면** 그 매물의 폴더에 저장됩니다. 같은 이름의 엑셀을 **교체**하면 그 매물 내용이 새 파일로 바뀝니다.
  (웹에서 직접 고친 항목은 그대로 유지)
- 같은 이름의 파일이 이미 있으면: 기본은 **둘 다 보관**(새 파일 이름 뒤에 `_2`),
  **교체** 를 체크하면 기존 파일을 매물 폴더의 `_백업\날짜시각\...` 으로 옮긴 뒤 새 파일로 바꿉니다. (`_백업` 폴더는 매물로 읽지 않음)
- 엑셀·CSV·JSON·TXT 매물 파일만 저장하고 사진·PDF 등은 건너뜁니다. 파일 하나 20MB, 한 번에 300개까지.
- 올린 뒤 바로 매물을 다시 읽고 "새 매물 N건, 올린 파일에서 읽은 매물 N건" 을 알려줍니다. 0건이면 소재지·면적·매매가 항목을 확인하세요.
- 관리자로 로그인한 상태에서 검색하면 매물 카드에 **연락처·전체 지번·원본 파일**이 함께 표시됩니다.

- 공개 전에 손님에게 보여줘도 되는 정보인지(지번 가림, 연락처 숨김) 한 번 더 확인하세요.

## 4. 사용법

```powershell
# 매물 수집·정제 (오류·중복 상세 보고서 포함)
python main.py sync --report

# 손님 문의로 추천 (대화형)
python main.py recommend "김철수 사장님, 양평 쪽 전원주택 지을 땅 200평 정도, 3억 이하, 맹지 제외, 남향" --name 김철수

# 대화형 상담 모드 (문의를 여러 번 입력)
python main.py chat

# 저장된 손님 조건으로 전체 매물에서 선제 탐색 / 폴더 감시하며 새 매물 알림
python main.py proactive
python main.py watch --interval 600

# 정제된 매물을 엑셀로 내보내기
python main.py export --out 정제된_토지매물.xlsx
```

추천 화면의 명령:

| 입력 | 동작 |
|---|---|
| `Enter` 또는 `n` | 마음에 안 듦 → **다음 순위 매물** (`n 너무 멀어요` 처럼 사유 기록 가능) |
| 그냥 말로 입력 | `마음에 안 들어요`, `너무 비싸요`, `채광이 별로` → 다음 순위 (사유 학습) / `좀 더 싼 걸로`, `여주 쪽도` → 조건 수정 |
| `w` | 지금까지 학습한 손님 취향 보기 |
| `p` | 이전 매물 |
| `t` | 남은 상위 5개 목록 |
| `d` | 상세 정보 (연락처, 원본 파일, 중복 출처, 가격 변동) |
| `f <피드백>` | 조건 수정 후 재추천 (예: `f 좀 더 싼 걸로`, `f 도로 붙은 땅`, `f 여주 쪽도`) |
| `l` | 관심 매물로 기록 |
| `s` | 손님 조건 저장 → 새 매물 선제 알림 대상 |
| `c` / `q` | 현재 조건 보기 / 종료 |

LLM 없이 실행: `python main.py --no-llm chat`
샘플 데이터로 연습: `python main.py --data-dir sample_data\토지 chat`

### 상담 예시

```
> python main.py recommend "음성군채광이 좋은 2억원대 아파트를 보여줘"
[이해한 조건] 지역=음성군 / 예산=2억원~2억 9,999만원 / 키워드=채광
[안내] '아파트'은(는) 취급 범위(토지) 밖이라, 토지 매물 중에서 나머지 조건으로 찾습니다.
 추천 1순위 / 6건  [E-3001] 충청북도 음성군 금왕읍 무극리 210-3 | 대 | 250평 | 2억 3,000만원
 특이사항: 정남향 평지, 채광 우수, 금왕IC 5분

> 마음에 안 들어요
 추천 2순위 / 6건  [E-3004] 충청북도 음성군 감곡면 오향리 301 | 잡종지 | 600평 | 2억 9,000만원

> 채광이 별로예요
 🧠 [학습] 특징(채광·조망 등) 중요도 ↑

 특이사항: 남동향 완경사, 햇빛 잘 듦, 전원주택 부지
```

"2억원대"는 2억~2억 9,999만원, "200평대"는 200~299평으로 이해하고, "채광 좋은"은 매물 설명의
남향·정남향·일조·햇빛 등과도 맞춰 봅니다.

## 5. 매물 추가하기

**방법 A - 프로젝트의 `매물` 폴더에 엑셀 넣기 (기본)**

```
Project/
├─ main.py
├─ 매물/                      ← 여기에 매물 엑셀(.xlsx)을 넣습니다
│   ├─ README.txt
│   ├─ 토지매물_입력양식.xlsx   ← 처음 실행하면 자동으로 생김
│   └─ (부모님 매물 장부.xlsx, 네이버/써브 정리 파일 … 하위 폴더도 OK)
└─ real_estate_agent/ …
```

1. 프로그램을 한 번 실행하면 프로젝트 폴더에 **`매물`** 폴더와 **`토지매물_입력양식.xlsx`** 가 생깁니다.
   (VS Code 왼쪽 탐색기에서 `매물` 폴더를 우클릭 → **Reveal in File Explorer** 로 열 수 있고,
   웹 관리자 화면의 **📂 매물 폴더 열기** 버튼도 있습니다)
2. 입력 양식을 엑셀로 열어 **'매물입력'** 시트에 한 줄에 매물 하나씩 적고 저장합니다.
   주황색 칸(소재지·면적·매매가)은 필수, **특이사항**에 "정남향, 햇빛 잘 듦" 처럼 적어두면 "채광 좋은" 검색에 걸립니다.
   이미 쓰시는 엑셀 장부가 있으면 그 파일을 `매물` 폴더에 그대로 복사해도 됩니다.
3. 웹 관리자 화면에서 **매물 폴더 다시 읽기** (또는 프로그램 재시작) → "매물 현황" 건수가 늘었는지 확인

> `매물` 폴더의 엑셀은 소유자 연락처가 들어 있어 **GitHub 에 올라가지 않도록** `.gitignore` 에 설정되어 있습니다.
> 그래서 `git pull` 로 새 코드를 받아도 매물 파일은 그대로 남습니다. (대신 따로 백업은 해두세요)

**매물 하나 = 폴더 하나 구조도 그대로 읽습니다**

```
매물/
└─ 음성군/                                              ← 지역 폴더 (주소에 지역이 없으면 앞에 붙임)
    └─ 음성군 감곡면 문촌리 417-2 외 36필지(물류부지)/    ← 매물 폴더: 이름 = 주소, (괄호) = 용도·특징
        └─ 음성군 감곡면 문촌리 417-2 외 36필지.xlsx      ← 매물 정보 엑셀
```

- 폴더(또는 파일) 이름에 `○○리 123-4` 같은 **지번이 들어 있으면 그 폴더 전체를 매물 1건**으로 봅니다.
  폴더 안에 엑셀이 여러 개면 합쳐서 읽습니다.
- 엑셀 안은 아래 세 형태를 모두 알아봅니다.
  1. **필지 목록표** (지번·지목·면적 … 여러 줄 + 합계 줄) → 면적 합산, 지목·용도지역은 면적이 가장 큰 것, "37필지 일괄" 표시
  2. **물건 정보지** (`소재지 | 값`, `매매가 | 35억` 처럼 항목 옆이나 아래에 값)
  3. **한 줄짜리 표** (일반 장부 양식에 매물 1줄)
- 총 매매가는 `매매가·총액·매도가` 항목 → `합계` 줄 → 필지별 금액의 합 순서로 찾습니다. 못 찾으면 보고서에 [ERROR] 로 표시됩니다.
- 폴더 이름의 (괄호) 내용(예: 물류부지)은 특이사항에 들어가 검색에 쓰입니다. ("물류창고 부지" 검색 → 이 매물)
- 손님 화면에는 `음성군 감곡면 문촌리 *** 외 36필지` 처럼 지번이 가려집니다.

이 구조와 일반 장부 파일(표 한 줄 = 매물 1건)을 한 `매물` 폴더 안에 섞어 써도 됩니다.
`음성군`, `기타지역` 처럼 폴더를 몇 개 만들어도 **모든 하위 폴더를 읽습니다.**
예) `매물/기타지역/문경시/산북면 대하리 12(임야)/정보.xlsx`, `매물/기타지역/밀양시 산내면 가인리 5/…`, `매물/기타지역/봉화군 물야면 오전리 77.xlsx` 모두 가능

**지역 검색**: 전국 시·군 이름표가 들어 있어 "문경 임야", "밀양 쪽 땅", "경북 땅"(→ 문경시·봉화군·안동시 … 매물) 처럼 찾을 수 있습니다.
"음성" → **음성군**, "여주" → **여주시** 처럼 시·군을 빼고 써도, "음성창고"처럼 붙여 써도 정식 이름으로 바꿔 찾습니다.
(GPT 가 문장을 해석할 때도 같은 규칙으로 바로잡습니다. "음성읍 땅"처럼 읍·면을 콕 집으면 그 읍·면만 찾습니다)
찾는 지역·조건에 맞는 매물이 없으면 다른 지역 매물을 대신 보여주지 않고 **"해당 조건에 맞는 매물이 없습니다."**,
매물을 보여주다가 다 떨어지면 **"해당 조건에 맞는 매물은 더 이상 없습니다."** 라고 안내합니다.
(예산 "30억 이상", 면적 "500평 이상" 같은 하한도 지켜서, 훨씬 싸거나 좁은 매물은 나오지 않습니다)
- `음성군`·`진천군`·`청주시` 처럼 **시/군/구 이름인 폴더**만 주소 앞에 지역으로 붙입니다. `기타지역` 같은 이름은 붙이지 않고,
  주소의 시/군은 엑셀의 `소재지` 칸에서 가져옵니다. (기타지역 폴더의 매물은 엑셀 소재지에 시/군까지 적어주세요)
- 관리자 화면의 매물 정리 보고서에 **폴더별 매물 수**(예: `음성군 12건, 기타지역 5건`)가 나오니, 0건인 폴더가 있으면 보고서의 [ERROR] 줄을 확인하세요.

**방법 B - 웹 관리자 화면에서 올리기**: 관리자 → **📄 입력 양식 내려받기** → 작성 → **매물 파일 올리기**
(올린 파일은 매물 폴더의 `웹업로드` 폴더에 저장됩니다)

이미 쓰고 계신 엑셀 장부가 있다면 양식을 새로 쓸 필요 없이 그 파일을 그대로 넣어도 됩니다.
컬럼 이름이 아래 표와 비슷하면 자동으로 알아봅니다. 읽지 못한 매물은 관리자 화면의 **매물 정리 보고서**에 이유와 함께 나옵니다.

> 검색 결과가 0건이면: ① 관리자 화면 "매물 현황"의 **매물 폴더 경로**와 **건수**가 맞는지,
> ② 찾는 지역의 매물이 있는지, ③ 보고서에 [ERROR] 로 빠진 매물이 없는지 확인하세요.
> 매물 폴더를 프로젝트 밖의 다른 곳으로 쓰려면 `.env` 에 `REA_DATA_DIR=경로` 를 적습니다.

## 6. 네이버 부동산 · 부동산써브 데이터에 대해

네이버 부동산과 부동산써브는 **공개 API 를 제공하지 않고, 이용약관에서 자동 수집(크롤링)을 금지**하고 있습니다.
그래서 이 프로그램은 크롤러를 넣지 않았고, 대신 다음 방식을 씁니다.

1. 부모님이 각 플랫폼에 올린 매물 목록(중개사 관리 화면 등에서 내려받거나 정리한 엑셀/CSV)을
   `토지\네이버부동산\`, `토지\부동산써브\` 같은 하위 폴더에 넣습니다.
2. 수집기가 출처를 자동으로 표시하고, 장부와 겹치는 매물은 중복 제거로 하나로 합칩니다.

정부 공공데이터(국토부 실거래가)와 GIS(브이월드)는 공식 API 를 쓰므로 키만 발급받으면 바로 연동됩니다.
나중에 공식 API 를 제공하는 플랫폼이 생기면 `collectors/base.py` 의 `Collector` 를 상속해 수집기를 추가하면 됩니다.

## 8. 개인정보 주의

- 매물 폴더에는 소유자 연락처가 들어 있습니다. LLM 에 보내는 정보에서는 연락처를 빼고 보냅니다.

- `.env`(API 키), `data/`(DB), `logs/` 는 git 에 올라가지 않도록 `.gitignore` 에 넣어 두었습니다.
  실제 매물 파일은 저장소에 올리지 마세요.
